# **App Name**: SkillGap AI

## Core Features:

- Resume Upload and Parsing: Allow users to upload their resumes in PDF format and parse the text content.
- AI-Powered Skill Gap Analysis: Analyze the resume content using the Gemini AI to identify missing skills based on a selected job role.  The analysis serves as a tool to help the user understand their gaps.
- Course Recommendations: Suggest relevant courses from platforms like Udemy and Coursera to address identified skill gaps.
- Internship Listings: Display a list of available internships with filtering options for location.
- User Authentication: Implement user login and signup functionality.
- Landing Page: Create a landing page with a smooth transition and company information.
- Firestore integration: Utilize Firestore to store user data, resume analyses, and internship details.

## Style Guidelines:

- Primary color: Very pale lavender (#F3E5F5) for the background.
- Secondary color: Soft lavender (#E1BEE7) for cards and sections.
- Accent color: Deep purple (#8E24AA) for buttons and highlights.
- Text color: Dark purple (#4A148C) for optimal readability.
- Background: White (#FFFFFF) for containers with lavender accents for better readability.
- Headline font: 'Playfair', a modern sans-serif, offering an elegant, fashionable feel; best for headlines.
- Body font: 'PT Sans', a humanist sans-serif that complements the Playfair headline while offering readability; best for body text.
- Use minimalist icons to represent different skills and job roles.
- Employ a clean and modern layout with ample whitespace for readability.
- Implement subtle animations for transitions and loading states.
